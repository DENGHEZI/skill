# DIC 作图

面向土木/材料 DIC 结果作图与图片检测，覆盖两类场景：
- **A. 界面粘结/直剪**（ECC-煤矸石混凝土、UHPC-NC 复合）：应变场 exx 用 VIC rainbow
- **B. 土木结构损伤识别/振动/抗震/SHM**：位移场 Ux/Uy（有符号，双向色标）、应变场 εxx/γxy、
  2×2 全场网格、开裂位置叠加

作图规范由真实 DIC 论文图"训练"反推（详见 `references/dic-plotting-conventions.md`），
并附论文表3实测数据与 `data/sample_civil_beam/` 土木梁样例，用于校准和验证。

**版式总览（三种论文风格，按需选）**：
- **A4 · Fig.7/8 版式**（`dic_ref_grid.py`）：荷载进程(列) × 应变分量(行)，每行一条横向色标
- **A5 · Fig.12 版式**（`dic_fig12_specimen.py`）：试件(行) × 时相(列)，每面板一条竖向色标 + 键槽阶梯轮廓
  —— 对标 赵卫平等《ECC-煤矸石混凝土界面黏结性能试验研究》图12


## 何时用

- 要画 DIC 应变场云图（多加载阶段对比，VIC 软件风格）
- 要画界面直剪的荷载-滑移（P-s）曲线 / 荷载-位移曲线
- 要从一张 DIC 云图图片中**检测**应变集中带 / 开裂区（面积占比、条带位置）
- 要按论文风格批量出图（黑框内刻度、双列顶部图例、e 计数法色标）

### A5. 直剪界面 Fig.12 风格（`dic_fig12_specimen.py`，多试件 × 多时相）

对标 **赵卫平等《基于数字图像相关技术与声发射的 ECC-煤矸石混凝土界面黏结性能试验研究》
（《建筑结构学报》2025, 46(5)）图 12「x 向应变场变化云图」** 逐项反推的版式（**逐点取色 + 逐行量几何**）。
与 A2/A4（Fig.7/8 版式）的**根本区别**：A2/A4 是"荷载进程(列) × 应变分量(行)"，
A5 是"**试件(行) × 时相(列)**"，且**每个面板自带一条细竖色标**、叠加**键槽阶梯轮廓线**。

| 要素 | A4（Fig.7/8, `dic_ref_grid.py`） | **A5（Fig.12, `dic_fig12_specimen.py`）** |
|---|---|---|
| 行 | 应变分量 Exx/Eyy | **试件**（8~10 个，不同键槽参数）|
| 列 | 荷载进程 0/20/…/100% | **时相**（未配筋: 0.90/0.95/1.00 Pu；配筋: 初裂/中间/峰值）|
| 色标 | 每行一条**横**色标 | **每面板右侧一条细竖**色标，刻度在**左**侧、e 计数法 |
| 配色 | 饱和 diverging rainbow | **参考图实拍 rainbow**（草绿底 `#58b058`(88,176,88)、紫 `#8040a0`(128,64,160)、色标顶红 `#d09595`）；**注意不是低饱和** |
| 轮廓 | 可选钢棒 | **黑色键槽阶梯折线**（Z 形试件几何）|
| 底纹 | 纯色场 | 可选 `--texture` 叠**极淡散斑底纹**（最像参考图实拍）|
| 标题 | 无 | 组下方 `(a) 试件CE-2-2-0-0`；面板下方 `0.90 P_u` |
| 注记 | 无 | 可选青框+箭头+「部分开裂应变释放」|

**几何（实测像素，脚本已硬编码此比例）**：面板 78×158 px → **宽:高 = 1:2.03**；
色标条 ≈5 px → **面板宽 × 0.064**（1/15.6）；面板↔色标距 = 面板宽 × 0.064（紧贴）；
组间距 = 面板宽 × 0.436；组行距 211 px。

**破坏力学规律（"符合破坏的力学规律"，实测单面板结构）**：
- 背景 = 大面积**绿**（中应变，轻微斑驳），**不是**整片红/紫；
- 界面 = **黑色粗阶梯折线**（Z 形）贯穿上下面板；
- 高应变 = 沿界面线散布的**离散橙红小热点**（小而密），**不是**连续粗红带；
- 低应变 = 界面右半**青/蓝**块 + 右下角零星**紫**块（开裂释放）；
- 随荷载进程：**热点增多/变亮、局部贯通**。未配筋(脆性)集中在峰值瞬间；配筋(延性)逐步增强。
脚本 `--demo`
即按此规律合成。

```bash
# ① 演示(论文 8 试件 × 3 时相, 按破坏力学规律合成, 无需数据; --texture 最像参考图)
"$PY" "$S/dic_fig12_specimen.py" --demo --texture --out fig12.png --dpi 300

# ② 真实 DIC 导出(单试件多阶段作 1 行) —— 快速出图
"$PY" "$S/dic_fig12_specimen.py" --fields ./dic_fields \
      --stages 30,40,49 --labels "0.30 P_u,0.65 P_u,1.00 P_u" \
      --row-title "(c) 试件CE-2-2-0-0-r" --dilate 2 --out fig12_real.png

# ③ 多试件(最灵活) —— 用 JSON 清单精确控制每行每面板
"$PY" "$S/dic_fig12_specimen.py" --manifest fig12.json --out fig12.png
#   manifest.json 格式:
#   [ {"title":"(a) 试件CE-2-2-0-0",
#      "panels":[{"path":"f/a_090.npz","label":"0.90 P_u","field":"exx"},
#                {"path":"f/a_095.npz","label":"0.95 P_u"},
#                {"path":"f/a_100.npz","label":"1.00 P_u"}]}, ... ]

# ④ 青框+箭头+「部分开裂应变释放」注记(画在第 3 列面板)
#    ⚠️ 坐标是**数据坐标**: demo 面板 ext=0~1 所以 0~1 分数恰好可用;
#       真实场要按面板 extent 给(如 x∈[296,744] y∈[40,968] 就得写 "545,200,130,210,...")
"$PY" "$S/dic_fig12_specimen.py" --demo --annotate "0.70,0.63,0.14,0.14,部分开裂应变释放" \
      --annotate-panel 2 --out fig12_annot.png
```

参数速查：
- **配色**：`--cmap ref`(默认, 按参考图取色的柔和低饱和) / `vivid`(旧饱和版) / `rainbow` / `jet`；`--pct 92` 控制上限百分位（全局统一，便于跨试件对比）；`--vmax` 手动定标。
- **色标刻度**：e 计数法（如 `5.0e-2`）；竖直、紧贴面板、刻度在左（参考图风格）。
- **底纹**：`--texture` 叠极淡散斑底纹（`--texture-alpha 0.18` 控浓淡），最接近参考图实拍观感。
- **平滑/连通**：`--sigma 4`(归一化卷积)、`--minsup 0.05`、`--dilate 2`(裂缝区连成重色带)、`--smooth 1.0`(去方块)。实测**真实粗网格场 σ=1.2 最像参考图**（沿界面细亮带 + 明显青蓝释放斑）；σ≥2 会糊成一大片红。
- **轮廓**：`--interface auto`(按试件矩形自动生成 Z 形键槽阶梯线) 或 `--interface "x,y;x,y;..."`(显式点，数据坐标)。
- **★ 真实 DIC 观感（照片底图）**：
  `--texture-dir <dir> --texture-map "0=stage_00001_1,1=stage_00041_1,..." --tex-ds 4
   --tex-x0 291 --tex-x1 748 --tex-y0 40 --tex-y1 968 --tex-down 1 --field-alpha 0.78`
  应变场以 alpha 半透明叠在散斑照片上，**失效区(NaN)全透明露出照片** —— 裂缝带/匹配失效处
  直接看到照片里的真缝，这是 VIC/GOM 那种真实软件观感的关键。`--tex-down 1` 别降采样（散斑要清晰）。
  ⚠️ **必须配 `--y-flip`**：ds-px 的 y 是「从照片顶部往下数」的，默认 ylim(y0,y1) + origin=lower
  会把整块试件上下颠倒 —— 场和裂缝线内部自洽看不出来，一叠照片底图就露馅（缝的宽开口端跑到底部）。
  ⚠️ 热区收窄用 `--dilate 0`（贴线窄红带，对标参考图）。
- **★ 紫底参考观感 = 不对称色标，不是换色图**：
  `--vmin-rel 0.10`（下限 = -vmax×0.10，配 σ=1.2 最像）。参考图 Fig.12 大多数面板**背景是紫**、
  界面带是**绿肩 + 红芯**，本质是参考图色标范围**不对称**（如 [-7.2, +72]），零应变落在色标
  **底部**→紫；对称 ±vmax 会让零应变落在色标**正中**→整版绿底 + 一坨实心红，与参考图气质
  完全不符（踩过：第九轮用户重贴 Fig.12 全图打回后才看破）。色标的 0 刻度会自动吸附到
  离 0 最近的等距刻度位（参考图色标也有 0 刻度）。vmin_rel 取 0.06~0.12，越小紫越深。
- **★ 真实裂纹线（对标参考图的细界面线，Fig.12 用这个）**：
  `--crack-line <txt>`（每行 `x,y` 数据坐标）+ `--crack-line-lw 1.4` —— DIC 的 trace 是粗网格
  平滑轨迹，跟照片里的锯齿缝**对不上**；用 `dic_crack_raster.py`（见下 A5b）从原始照片
  逐行抠出**像素级中心线**再传进来，细黑线走真实缝的锯齿路径 —— 既像参考图的细界面线，
  位置又真实。
  ⚠️ **别用 `--crack-band` 缝宽填充带当 Fig.12 的界面线**：带按真实缝宽画（中位 20 ds-px
  ≈ 面板宽 4%，顶部开口 20%），比参考图的细线重一个量级，整图变一大坨黑（踩过，用户两轮打回）。
  缝宽带只适合「裂缝形态特写」类图。
- **注记**：`--annotate "cx,cy,w,h,文字"`(可多次) + `--annotate-panel N`(第几列)。
  ⚠️ **cx/cy/bw/bh 是数据坐标（面板 extent），不是 0~1 轴分数**；文字用 `|` 代替换行符。
- **布局**：`--panel-h 2.05`(面板高 inch)、`--title-size 10.5`、`--dpi 300~600`。

**A5b. 真实裂纹中心线（`dic_crack_raster.py`，像素级）**

把照片里那条**锯齿缝**（有实际开口宽度、有分支）抠成一条折线，供 A5 `--crack-line` 使用：

1. 坐标：`ds-px × 4 = 原始 px`（DS=4，需按现场核对）；面板裁剪带 x/y 范围要与裁场脚本一致。
2. **逐行 80 分位当背景**、`暗 < 背景 − 40` 判缝。
   ⚠️ 坑：不能用**局部中值窗**做背景——缝顶部上百像素宽，中值窗整个落进缝里，
   缝内中值≈缝外中值，对比度被自己抹平（实测只检出 22 px）。
3. **先 σ=6 高斯平滑再判暗**。不平滑的话逐行「最长暗段」会在缝和散斑团之间来回跳（中心线乱飞）。
4. **连续性跟踪**：取窗口内纵向贯穿度最大的连通域当种子行，向上下各推一行，
   每行只接「离上一点最近的段」（|Δx|<150），中心 = 段内灰度加权质心；
   同时记下每行**左右边缘**——⚠️ 要在选中暗段里**再取「更深一档」的缝芯**
   （`gm < 背景 − drop_core(55)` 的连续段），否则缝边**阴影/损伤带**一起算进宽度，
   实测带宽是真缝的 2~3 倍，画出来一大坨黑（踩过：中位 28 → 取芯后 20 ds-px）。
   ⚠️ 直接按 span 最大挑主域会被顶部大暗斑抢走；按面积挑会把横向黑标线选进来 —— 两个判据都要。
5. **边缘去毛刺（不做就是假缝）**：先插值补跟丢行 → 滑动中位数(101)剔两类离群 ——
   ① 中心偏 >70px（跳到旁支）② **宽度 > max(2.2×中位宽, 90px)**（旁支把宽度撑爆成"小翅膀"，
   中心不偏所以①抓不到；阈值 3× 太松，160~240px 翼展照样混进来——踩过）
   → 重插值 → median(25) → **再沿 y 高斯(σ≈med/3)**：把逐行**平台状方波台阶**转成
   照片缝边那种有机斜线（不加大尺度锯齿也保不住）。
6. **底端渐灭收尖**：照片底部缝本来就自然尖灭（实测最后 8% 无暗段），延伸段宽度在前 55% 内
   线性收到 0 —— 别拖恒宽细线（发丝线，假）。
7. 产出 `crack_band.txt`（y,xl,xr，缝宽中位 20 ds-px/最大 88）+ `crack_rgba.png`。

> **配色逐点取自该参考图**：灰绿底 `(129,186,110)`、靛紫 `(91,71,152)`、砖红 `(179,81,72)`、

### A3b. 大变形 / 稀疏关键帧 → `dic_large_deform.py`（当 A3 失败时用它）

**症状**：`dic_raw_to_field.py` 跑出 `valid=0`、`Umed=nan`、cval 中位 ~0.2。
**根因**：A3 假设**相邻帧位移很小**（逐帧跟踪，搜索窗默认 ±6 ds-px）。但试验常只导出
**稀疏的关键阶段**（如 stage_00001/00041/00054/00059，跨几十个荷载步），帧间位移可达
**±100 ds-px（数百原始像素）**，远超搜索窗 → 匹配全军覆没。

诊断方法（判断是不是这个毛病）：用整图互相关估计全局位移，若量级达几十~上百 ds-px 即确认。

```bash
# 诊断: 该类数据典型输出  stage_00041: dy=+57 dx=+1 ds-px, 峰值ZNCC 0.687
python diag_global2.py
```

解法：**coarse-to-fine + reliability-guided 传播**，本脚本已实现：
1. **稀疏种子**：粗网格(--seed-step)上大范围(--seed-r，默认±128) ZNCC 粗配准；
2. **外点剔除**：邻域一致性 + 可靠性百分位筛掉误配种子；
3. **插值预测**：种子双线性插值出全网格初始位移（捕获大位移趋势）；
4. **局部精化**：每点以预测为中心在小窗(--refine-r)内精搜 + 抛物线亚像素；
5. **应变**：`--strain-win`(默认5) **局部最小二乘平面拟合**求应变（不用逐点差分，否则位移噪声
   被微分放大成虚假大应变：实测 std 可从 5% 降到 ~1%）。

```bash
# 【推荐】增量模式 —— 相邻帧作参考、位移累加
"$PY" "$S/dic_large_deform.py" --indir ./Images --outdir ./dic_fields_inc --channel 1 \
      --step 16 --seed-step 64 --incremental --strain-win 5
"$PY" "$S/dic_ref_grid.py" --fields ./dic_fields_inc --stages 0,1,2,3 --rows exx,eyy \
      --labels "初始,S41,S54,S59" --unit "%" --smooth 1.2 --out DIC_exx_eyy.png --dpi 300
```

**为什么 `--incremental` 关键**（实测对比，同一批数据）：

| 模式 | stage54 有效率 | stage59 有效率 | 中位位移(→) | 单调性 |
|---|---|---|---|---|
| 绝对参考(全部对齐首帧) | 27.1% | 27.1% | 55→16→15 px | ❌ 非单调 |
| **增量模式** | **61.4%** | **62.8%** | **56→175→298 px** | ✅ 单调递增 |

关键参数：`--ds`降采样 `--half`子集半宽 `--seed-r`粗搜半径(≥帧间最大位移)
`--refine-r`精化半径 `--strain-win`应变窗(1=逐点差分,不推荐)。

> **结果校验**：出图后务必打印 uy/ux 直方图。若呈**双峰**且其中一峰跨帧几乎不变，
> 先别急着判为误配 —— 很可能是**试件外的静止夹具/背景**。画一张空间布局图
> （每个网格点按位移大小打 S/M）即可分辨：真正的直剪试件会呈现清晰的
> **左半静止 / 右半运动**，交界即剪切界面。<br>
> 反之若静止区散布成噪点，才是真的误配，需调大 `--half` 或放严 `--rel-max`。

### A3c. 直剪/拉拔试件：从位移场提取**裂缝轨迹 + 两侧滑移**（裂痕保留核验）

场景：单条竖向裂缝把试件分成"固定块 + 被拉块"（上传图那种带中心预埋筋的拉拔/直剪试件）。
目标是回答两件事：① **DIC 抓到的界面和肉眼裂缝是否重合**（=裂痕有没有被保住）；② 裂缝张开/滑移多少。

**已实测可用的调用（4504×4096 散斑 TIFF，ds=4）**：
```bash
"$PY" "$S/dic_large_deform.py" --indir DIR --channel 1 --incremental \
      --ds 4 --half 24 --seed-step 48 --seed-r 192 --refine-r 14 \
      --cval-min 0.45 --peakgap 0.02 --outdir fields
```
- 帧名 `stage_000NN_{ch}.tiff` **按通道分开**：`--channel 1` 只吃 `*_1.tiff`。
  用户常混传两个通道（如 `00035_0` + 其余 `_1`），**ch0 单独一帧无法做时序**，如实说明即可。
- **放宽 `--peakgap`(0.08→0.02) 与 `--cval-min`(0.60→0.45) 是纯增益**：
  实测有效率 62.7/65.9/67.8 % → **67.6/70.6/72.6 %**，而位移中位数几乎不变
  (55.9→55.8、174.9→174.4、298.3→297.6 ds-px) ⇒ 补回的都是被周期歧义误剔的真点，未引入误配。
  判据：**放宽后若位移中位数基本不动，就说明没有引入假匹配，可以放心放宽。**

**界面轨迹提取三步（缺一步就会被周期伪峰甩飞）**：
1. 裂缝带 `band` = (`|du/dx|` 超 p88) ∪ (`|exx|` 超 p90) → 开闭运算 → **删掉面积 < 6 格的孤立小岛**（否则边缘留下小红框）。
2. **全局锚点 x0 = `band.mean(axis=0)` 的峰值**（先沿 x 高斯平滑）。
   ⚠️ **千万不要用「uy 沿 x 的最大跃变」当锚点**：`nan→0` 的失效区边界会造出假梯度峰，
   实测把锚点拉到 x=27 ds-px（真值 ≈488），轨迹整条报废。
3. 逐行在 `x0 ± 12` 格内、且**只在 band 内**取 `|du/dx|` 最大值 → 再 `median_filter(size=5)`。
   实测轨迹 x=424~616 ds-px，与原图肉眼裂缝**完全重合**。

**量化输出（三个互补指标）**：
- 界面两侧滑移 `Δuy`：轨迹左右各 8 格取 uy 均值之差（沿高度近似恒定 → 画出来是水平线）。
- 裂缝影响带宽度：band 每行的 (max−min) 格宽 → 随荷载单调变宽。
- **真实缝宽（推荐，最硬的证据）**：拿原图灰度，在 x0±90 ds-px 开窗，
  阈值 `p80 − 0.45·(p80−p20)`，取**最长连续暗段**。未开裂帧作对照应最小。
  实测 92 → 112 → 140 → 178 原始px（stage 1/41/54/59）单调增大。

#### ★★ 四类「静默失真」——不报错但结论全废（AI/脚本量化指标通用）

写任何基于**位移梯度**的量化指标（裂痕区 MAE、跳变误差、应变集中区）时，下面四处
都会**静默给出错误数字**。共同特征：**不抛异常、日志干净、图看着正常**，但指标恒为 0 / nan / 恒定垃圾值。

1. **多取一层索引 → 拿到"第一行"而不是整场**（最隐蔽）
   `(1,H,W)` 或 `(1,1,H,W)` 张量写 `x.numpy()[0, 0]`：对 `batch[i]`（形状 `(1,1,H,W)`）
   这是剥 2 层 → 只剩 `(W,)` **第一行**；对 `batch[i][0]`（`(1,H,W)`）剥 2 层 → 剩 `(H,)`。
   实测：`u` 幅度 ±10.4 px 读出来是 ±1.36，梯度 max 从 0.78 变成 0.012（差 60 倍），
   于是"裂纹带"阈值永远筛不到格子 → 跳变误差**整列 nan**，全图 RMSE 却依然正常。
   ```python
   def _2d(t):                      # 任意 (...,1,H,W)/(1,H,W)/(H,W) -> (H,W)
       a = t.detach().cpu().numpy() if torch.is_tensor(t) else np.asarray(t)
       return np.squeeze(a)         # 别手写 [0]/[0,0]，层数一错就静默失真
   ```
   **自检**：`assert _2d(u).shape == (H, W)`，并打印 `u.max()-u.min()` 与理论幅值对一下。

2. **`np.gradient` 对 2D 输入默认只算一个轴**
   传 `(H,W)` 而不指定 `axis` → 返回长度 1 的 list，`[1]` 越界或拿到错轴。
   一律写 `np.gradient(f, axis=(0, 1))`（返回 `[d/dy, d/dx]`，**注意顺序是 y 先 x 后**）。
   同理 `np.hypot` **只接受 2~3 个参数**，4 个会 `TypeError` → 必须嵌套
   `np.hypot(np.hypot(a, b), np.hypot(c, d))`；**绝不要用 `try/except: continue` 吞掉它**，
   实测正是被静默吞掉后指标全 nan、最优模型选择（`nan < inf` 恒 False）退化成"最后一轮"。

3. **固定绝对阈值遇到量级变化就整列作废**
   `|du/dx| > 0.30` 这种硬编码阈值，在 amp 从 8 变到 24 时裂纹带可能不足 20 格 → 返回 nan。
   改用**分位数自适应**：`m = aJ > np.percentile(aJ, 92)`（top 8 %，天然保证样本量）。

4. **解包 batch 时把"预测"参数覆盖掉（最恶劣，实测 28 分钟训练报废）**
   ```python
   def grad_metrics(pred_u, pred_v, batch, kinds):
       up, vp, ref, d, ug, vg = batch[:6]   # ← 灾难: up/vp 立刻变成两张灰度图!
   ```
   指标从此算的是「图片 vs 位移真值」→ **每个 epoch 返回一模一样的常数**（不 nan、不报错），
   best 选择停在 epoch 1、baseline 也全错。重构出"指标函数"时，**预测参数名绝不能出现在
   对 batch 的解包里**。

**终极自检两连（能抓住上述全部四类，写完指标当场必跑）：**
```python
# ① 恒等测试: 真值当预测喂进去, 必须精确返回 0
g0, _, _, j0 = grad_metrics(ug, vg, batch, kinds)
assert abs(g0) < 1e-6 and abs(j0) < 1e-6
# ② 平移测试: 预测 = 真值 + (+1,-1)px, grad区MAE 必须恰为 sqrt(2)≈1.414
g1, _, _, _ = grad_metrics(ug + 1.0, vg - 1.0, batch, kinds)
assert abs(g1 - np.sqrt(2)) < 0.05
```
**再加一条运行时判据**：训练日志里若某指标**逐 epoch 完全不变**（小数点后一位都不动），
而 loss/RMSE 在变 → 十有八九就是第 4 类（预测没进公式）。恒等/平移两连已内置进
`train_continue.py` 启动自检，可作模板。

### A3d. AI-DIC 续训：让网络**纠正粗配准抹平的裂缝**（裂痕保留的另一条路）

上面 A3c 是"从粗配准结果里找裂缝"；这条路是"**训练网络把粗配准丢掉的位移跳变学回来**"。
适合：粗配准在裂纹区把两侧位移**抹平成连续场**（跳变相对误差 >100 %）、
而全局 RMSE 又看着不离谱的场合。

**思路**（原型库 `ai_dic`，DICNet = U-Net 式 encoder-decoder 吃 `[I_ref, I_def, u0, v0]` 预测残差）：
1. 合成训练场，**把 `crack_field` 占比提到 50 %**、幅值提到接近真实（真实 stage41→59 单帧位移上百 px）。
2. 对每对样本先跑粗配准拿 `(u0, v0)` 当网络输入 → 网络学的是**残差**，不是绝对位移。
3. 考核**必须分两层**：全图 RMSE/MAE + **裂痕区（高位移梯度）MAE** + **裂纹跳变相对误差**。
   只有第三项能回答"裂痕还在不在"，前两项看不出区别。

**踩坑（每条都曾让结论完全失真）**：
- `coarse_to_fine` 返回 `(m, info)` **元组**，不是数组 → `m, _ = ...` 再 `fields_from_match(m, h, w)`。
- **搜索半径不是越大越好**：`amp=24px` 的 crack 场上 `r_coarse=8` → 粗配准 RMSE 7.60；
  放到 32 → **42.09**（周期散斑伪峰大量进入搜索窗，误配暴增）。
  正确做法是"适度放大 + 靠网络学残差纠正"，实测网络把 r=32 的 42.09 纠到 13.03（**−69 %**）。
- **`baseline` 必须在验证集上算**。用训练集算会让基线虚高（实测 1.91 vs 验证集 42.09，差 22 倍），
  对比结论直接翻转。
- `ai_dic.train.train_supervised` 在 `log=None` 时仍调用 `log(...)` → 必崩，**必须传 `log=print`**（库 bug）。
- `ai_dic.evaluate.rmse/mae` 返回 **float 而非 tuple**，`c_rmse, _ = E.rmse(...)` 会 TypeError。
- `ai_dic.evaluate.photo_err` **不支持 batch**（`grid_sampler` 批大小不匹配）→ 循环前 k 张求均值。
- **最优模型选择会静默退化**：若选择判据用 `nan`（见 A3c 末节），`nan < inf` 恒 False →
  存下来的是"最后一轮"权重却标称"最优"。必须 `np.isfinite(r) and r < best`。
  另一变种：指标函数解包 batch 时把预测参数覆盖成图片 → 指标**逐 epoch 恒定不变** →
  best 停在 epoch 1（实测 28 分钟训练因此报废重跑）。对策见 A3c 末节「终极自检两连」。
- 免训练 PINN 逐例优化（`refine`，300 it）在 CPU 上**跑不赢粗配准**，别指望它当兜底。

### A4. 期刊 Fig.7/8 风格网格（`dic_ref_grid.py`，中心绿=0 双向彩虹，最贴近论文版式）

按真实论文图（Structures 92 (2026) 112808 Zhong et al.，图 7/8）**逐项反推**的版式，用于
"荷载进程 × 应变分量"对比图。与 A2 的区别见下：

| 要素 | A2（`--grid-style`/`--real-grid`） | A4（`dic_ref_grid.py`，论文风格） |
|---|---|---|
| 色标 | VIC rainbow（单向） | **diverging rainbow，中心绿=0**（紫-蓝-青-绿-黄-橙-红）|
| 无效区 | NaN → **白** | **按 0 显示 → 绿底**（试件成整块绿，最像论文 0% 面板）|
| colorbar | 每行**竖直**、右侧、e 计数法 | 每行**横向**、行下方、右侧标注 `Exx/%` |
| 列标签 | 顶部 | **面板下方**（0,20%,40%,60%,80%,100%）|
| 稀疏场 | 原样 | **归一化卷积平滑**（--sigma/--minsup）读成连续条带 |
| 裁剪 | 全图 | 默认取 mask 并集**包围盒**（去空白背景）|
| 黑点 | 无（白底）| 无（**绿底，零黑点**）；可选 `--tex-alpha` 叠极淡底纹（默认 0）|

```bash
"$PY" "$S/dic_ref_grid.py" --fields ./dic_fields \
      --stages 0,10,20,30,40,49 --rows exx,eyy \
      --crop 380,800,0,815 --sigma 3 --minsup 0.05 --pct 90 --out ref_exx_eyy.png
```
- `--pct`（默认 90）控制每行色标上限百分位；损伤区离群大值用 `--pct 85~92` 避免整幅饱和。
- 彩色块只出现在**实测区**（裂缝/损伤区），其余为绿底 → 视觉即"应变集中带随荷载增强"。
- 若轮廓不是矩形（试件形状不规则），后续可加 `--mask-shape` 用并集掩膜裁形（暂用矩形）。

#### ★ 期刊试件样式（钢棒 + 标注）+ 去糙（v1.3.3 新增）
还原 Structures 92 (2026) 112808 图 7/8 的"试件块 + 加载端钢棒 + Loading end/Steel bar 标注"观感：

```bash
"$PY" "$S/dic_ref_grid.py" --fields ./dic_fields \
      --stages 0,10,20,30,40,49 --rows exx,eyy --steel-bar --out ref_exx_eyy.png
```
- **`--steel-bar`**：每个面板上下各叠一段灰色钢棒（加载端），首列下方加 "Loading end" / "Steel bar" 标注，
  与论文试件样式一致（钢棒在 `transAxes`，与数据坐标解耦，任何裁剪框都对齐）。
- **去糙（默认开）**：底层应变场仅数十格分辨率，放大显方块 → 渲染改用 **bicubic 插值** +
  场切片后 **`--smooth 1.2` 轻量高斯**（网格 cell）消除方块糙感；`--smooth 0` 可关。
- **像素（默认 dpi=600）**：期刊级分辨率；要更小文件用 `--dpi 300`。
- 配合 `--dilate 3` 让裂缝区连成连续重色带、区外仍绿底（见上节"重色只在开裂处"）。

#### ★ 最终定版：纯色场（零黑点）＝ 默认
用户多轮迭代后的结论：**保持论文观感 + 黑点全除** ⇒ 默认 `--tex-alpha 0`（纯色场）。

- **表现**：未测/低置信区按 0 显示 → **整块实心绿**；0% 面板就是一整块绿（与论文 Fig.7/8
  的 0% 面板完全一致），场上**没有任何散斑点/黑点**。
- **为什么不是"叠试件照片"**：本样本的"试件"本身就是约 1.7 万个圆点组成的散斑簇；只要把照片
  叠上去（哪怕 alpha 0.13、先柔化），绿底上仍会浮出一圈圈**深绿圆点** → 仍被视为"没除干净"。
  故正确做法是**完全不叠照片**，让应变场自己说话。
- **可选极淡纹理**（仅当确需"试件感"且用户明确接受底纹）：`--tex <照片> --tex-alpha 0.13 --tex-ds 4`
  —— 会先把照片 `gaussian_filter(2.2)` 柔化成底纹，再低透明度叠加；**不是默认**。
- 试件几何靠**裁剪框**（`--crop`）界定为矩形，与论文试件块一致。

#### ★ 让应变场"更连续" + 重色只在开裂处（用户最终要求）
论文 Fig.7/8 的要点是：**重颜色（红/蓝）只落在开裂/损伤区，其余低应变区是浅绿**。
实测数据只有 14–23% 被可靠追踪（即"打破周期性的裂缝区"，见数据质量须知），其余判据剔除。
因此正确做法是**只在裂缝区着色 + 连续化，绝不对全试件外推**：

1. **平滑条带（保真，默认先看）**：加大 `--sigma`（如 3→7）让裂缝区实测点扩成平滑宽条带，
   未测区仍绿底（局部条带 + 绿底，最贴近论文"局部高应变带 + 整体低应变"观感）。
   ```bash
   "$PY" "$S/dic_ref_grid.py" --fields ./dic_fields --rows exx,eyy --sigma 7 --out smooth.png
   ```
2. **裂缝区连成连续重色带（首选，推荐）**：`--dilate N`（如 3），从已着色的裂缝核心向外
   **膨胀 N 格**并在裂缝区内用最近邻连续填充 → 重色带沿裂缝连成片，区外一律绿底。
   实测核验：裂缝区内 57–86% 为非绿、区外 0%（重色严格只在开裂处）。
   ```bash
   "$PY" "$S/dic_ref_grid.py" --fields ./dic_fields --rows exx,eyy \
         --sigma 7 --minsup 0.04 --dilate 3 --out crack.png
   ```
   - ⚠️ 切勿用"全试件外推"：曾试 `--inpaint`（把未测区最近邻外推填满全试件），会把裂缝高应变
     **外溢到非开裂区**，违背"重色只在开裂处"，已废弃。
   - `--sigma` 控条带粗细、`--dilate` 控裂缝带连通程度，可反复调。

#### 去黑点（散斑）原则
所有网格/全场面函数均把**无效/低置信区设为 NaN**；A4 进一步把 NaN **按 0 渲染成绿底**，
因此 A4 出图**结构上不可能出现黑点**（绿是最低值，不是黑）。若输入是原始散斑照片，
务必先经 DIC 计算得到应变场再作图——云图显示的是应变场本身，**天然不含散斑黑点**。
如仍有"黑点"观感，几乎都是**叠了试件照片纹理**所致 → 去掉 `--tex` / 设 `--tex-alpha 0`。

#### 数据质量须知（实测踩坑）
- 实测一批原始散斑 TIFF（4096×4504，白底+约 1.7 万个 ~11px 随机黑点，覆盖率 25%）。
  探针发现该类散斑在**大尺度(~200px)存在像素级周期重复**（ZNCC 次峰 C2=1.0 与主峰 Cmax=1.0 重合）。
  后果：**整图全场面应变 DIC 不可靠**——相关面出现多个等大假峰，位移被周期假匹配主导，
  而真实刚体平移≈0；只有打破周期性的**裂缝/损伤区**能可靠追踪。
- 应对：① 时序 DIC 用"固定参考模板 + 峰值比判据"使整图周期区自动掩膜为白、仅裂缝区保留真实应变
  （见 A3）；② 若需全场面应变，请用 VIC-2D/Ncorr 等成熟软件导出 Exx/Eyy 再用 `--real-grid` 渲染；
  ③ 重新制样时喷更细、更高频、无周期性的随机散斑。

## 三种模式

### A. 全场云图 `dic_strain_field.py`
- 场景A（界面粘结，默认）：`--specimen` + `--stages`，输出应变场 exx（VIC rainbow）
  + 黑色键槽界面折线 + "部分开裂 应变释放"标注；`--keys 3`、`--mode ductile|brittle`
- 场景B（土木结构）：`--sample beam` 进入三点弯曲梁模式
  - `--quantity exx|ux|uy|exy`：应变场用 rainbow；位移场 Ux/Uy 用双向色标(蓝-白-红)，clim 对称
  - `--grid ux,uy,exx,exy`：2×2 全场网格，每幅独立 colorbar（损伤识别典型成图）
  - `--crack crack.csv`：叠加红色虚线开裂折线
- 真实数据：`--csv x,y,exx`（或 ux/uy/exx 列名均可，脚本按列名自适应）；`--npz`(键 x,y,exx*)
- 内置样例：`data/sample_civil_beam/`（beam_ux/uy/exx/exy.csv + crack.csv）

### B. P-s 曲线 `dic_load_slip.py`
- 无参 = 复现论文 Fig.9（表3 的 10 个试件实测 Pu/su 驱动，脆性竖直跌落 vs 延性软化平台自动区分）
- `--csv` 长表列名自动识别：specimen + slip/disp/disp_avg/位移 + load/load_kN/P/荷载 均可
- 多曲线适配：`--legend-cols 6 --legend-loc bottom`（图例移到下方不遮挡）、`--xlim/--ylim` 手动范围
- `--group pz`：按试件名前缀（p-/z-）分组画双栏
- `--summary`：输出峰值荷载 Pu / 峰值位移 su 汇总柱状图（论文 Fig.10/11 风格，p-蓝 z-橙双色）

### C. 图片检测 `dic_image_detect.py`
- 输入任意 DIC 云图 PNG/JPG → HSV 色相分割（红≈高应变、橙≈中高）
- 输出：高应变面积占比 %、条带数 n_bands、各条带 bbox/质心/面积、青框标注图
- **`--diverging`**：双向色标位移场(Ux/Uy)用 → 同时标记红色正极值与蓝色负极值（变形集中区）
- 用途：① 质检新生成云图 ② 反推他人图片的应变/位移集中位置 ③ 对比 assets/ 论文参考图
- 参数：`--hue-red 10 --hue-orange 48`（色相度）、`--min-area 0.15`（最小连通域%）、`--diverging`

### D. 直剪界面 Fig.12 风格 `dic_fig12_specimen.py`
- 多试件(行) × 多时相(列)，每面板右侧**细竖色标** + 键槽阶梯轮廓 + 组标题（对标论文 Fig.12）
- 配色默认 `ref`（按参考图取色的柔和低饱和）；`--texture` 叠极淡散斑底纹最像参考图
- `--demo` 按破坏力学规律合成；`--fields` 单试件多阶段；`--manifest` 多试件精确控制
- 详见 A5 节
