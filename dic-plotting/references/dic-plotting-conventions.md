## 5. 图片检测要点（dic_image_detect.py 依据）

- jet/rainbow 色标中 高应变=红(色相≈0°)、橙(≈10-45°) → HSV 阈值分割即可定位应变集中带
- 检测输出：高应变面积占比、条带数、各条带 bbox/质心 → 判断"初裂/集中/贯穿"阶段
- **双向位移场（Ux/Uy）**：用 `--diverging` 同时标记红色正极值与蓝色负极值（变形集中区），
  因为位移是有符号量，红=正向位移极值、蓝=负向位移极值，二者都是"变形/损伤集中"信号。

## 6.1 土木 DIC 典型物理量

| 量 | 符号 | 有符号? | 推荐色标 | 说明 |
|---|---|---|---|---|
| 水平位移场 | Ux | 是 | VIC_DIVERGING(蓝-白-红) | 顶压底拉，跨中反对称；开裂处水平错动 |
| 竖向位移场 | Uy | 是 | VIC_DIVERGING | 向下挠度，跨中最大；开裂处上下盘错动 |
| 轴向应变 | εxx | 否 | VIC_RAINBOW | 底部受拉集中，裂缝尖端正应变最大 |
| 剪应变 | γxy | 否 | VIC_RAINBOW | 跨中剪切带（竖向），随裂缝发展增强 |

## 6.2 成图规范（与界面粘结图互补）

- **位移场用双向色标**：零位移落在白色，蓝=负、红=正；clim 取对称 `(-vmax, +vmax)`。
- **应变场仍用 VIC rainbow**：零应变落青绿、高应变落红/深红（与 §1 一致）。
- **开裂位置叠加**：DIC 检测出的开裂折线用红色虚线叠加（`--crack crack.csv`）。
- **2×2 全场网格**：损伤识别论文常把 Ux/Uy/εxx/γxy 并排成 2×2 网格，每幅独立 colorbar
  （`--grid ux,uy,exx,exy`），便于对照定位损伤。
- **长构件全景条带**：梁/柱 DIC 扫描常为宽幅矮图（如 1382×476），应变/位移沿长度方向分布，
  适合横向排布多阶段。
- **阶段规律（三点弯曲梁示例）**：加载↑ → 跨中底部 εxx 受拉集中带显现 → 裂缝自底部向上
  生长（crack_frac 随 stage 增大）→ 峰值阶段跨中形成贯穿开裂、位移/应变在裂缝处出现间断。

## 7 直剪界面 Fig.12 版式（多试件 × 多时相，`dic_fig12_specimen.py`）

对标 赵卫平等《基于数字图像相关技术与声发射的 ECC-煤矸石混凝土界面黏结性能试验研究》
（《建筑结构学报》2025, 46(5)）图 12「x 向应变场变化云图」。

### 7.1 版式要素（逐项）
- **行 = 试件**（论文 10 个，不同键槽深度/角度/数量、配筋率、阴阳键齿材料），
  每组 3 个时相面板。
- **列 = 时相**：
  - 未配受剪钢筋试件（脆性，破坏迅速）：`0.90Pu / 0.95Pu / 1.00Pu`
  - 配受剪钢筋试件（延性）：初裂 / 中间时刻 / `1.00Pu`（峰值）
- **每面板右侧竖一条彩虹 colorbar**（不是每行一条！），刻度 e 计数法（如 `5.3e-1`、`-8.8e-1`）。
- **黑色阶梯折线** = 试件/键槽界面轮廓（Z 形试件几何，阶梯 miter 折线）。
- 面板下方：荷载/位移标签（`0.90 P_u`）；组下方居中：试件编号标题（`(a) 试件CE-2-2-0-0`）。
- 可选：**青框 + 箭头 + 「部分开裂应变释放」**（标注局部应变释放区）。
- 底图：绿=低应变/0，红黄=正应变集中（界面剪切带），蓝紫=负应变（开裂应变释放）。

### 7.2 破坏力学规律（图必须体现）
1. 加载初期：全场接近均匀（近绿），应变无明显集中。
2. 裂缝发展阶段：结合界面附近出现**竖向应变集中带**（红黄），并在键齿/键槽根部出现局部热点。
3. 接近/达到峰值：主裂缝萌生贯通，应变集中带**更窄更强、贯穿界面**（贯穿条带）。
4. 部分区域开裂后**应变释放**（转蓝紫）→ 用青框注记标出。
5. 未配筋试件（A/C 类脆性）集中在峰值瞬间；配筋试件（延性）应变带随荷载逐步增强、出现次生带。

### 7.3 破坏模式（论文结论，用于标注/选样）
- A 类：键齿被剪断（裂缝自键齿根部发育、贯通）→ 凸出键齿嵌固键槽
- B 类：键槽被剪坏（裂缝自键槽根部发育）→ 键槽嵌固键齿
- C 类：键齿键槽均有剪坏（裂缝向两侧发育）
- D 类：未设键槽，裂缝沿结合界面发展

### 7.4 与 A4（Fig.7/8 版式）的区别

**场的力学结构（关键，别搞错）**：
- 背景 = 大面积**绿**（中应变，带轻微斑驳），**不是**整片红或整片紫；
- 界面 = **黑色粗阶梯折线**（Z 形），贯穿上下面板；
- 高应变 = 沿界面线散布的**离散橙红小热点**（小而密），**不是**连续粗红带；
- 低应变 = 界面右半的**青/蓝**块 + 右下角零星**紫**块（开裂释放）；
- 随荷载进程：热点增多/变亮、局部贯通。

> 色标**很细**（宽约面板 1/15.6）、**紧贴面板右侧**、刻度数字在**左**侧。
> 背景带**隐约散斑纹理** → 用 `--texture`（`--texture-alpha 0.18` 左右）还原。
> 数值量级：参考图色标顶约 `1e-1~1e-2`（如 `5.9e-1`、`3.0e-2`），demo 场按 ×1e-1 输出。
